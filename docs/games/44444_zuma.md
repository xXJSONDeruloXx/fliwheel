## Issue
The current HLE reaches the resource-backed GL path and exits cleanly. A
deterministic input receipt enters the Temple, advances through all built-in
instruction pages, closes the tutorial, and reaches `LEVEL 1-1: SPIRAL OF
DOOM`. The live scene includes the HUD, centered frog, animated marble/firing
state, and changing draw activity. The spiral track and colored marbles are
still malformed because several repeated material draws bind texture name
`0x8` without a matching captured upload, forcing an unrelated UV fallback.

then verify coherent track/marble placement. After that, drive clickwheel aim,
fire, collision, audio, and persistence. `0x1402000c` is an observed pixel
offset in the historical trace, not an established completion register.

# Reference material

This directory contains redistributable hardware and iPod-format references
used while improving the decrypted EAPP runner. Game bundles, firmware images,
FairPlay material, saves, and emulator captures stay outside the repository.

`documentation/` contains PortalPlayer, display, storage, and iPodLinux
references. The active runtime does not require any file in this directory;
the full-firmware emulator remains a sibling reference checkout.
